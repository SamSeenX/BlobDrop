# BlobDrop: 4096 - Viral Merge Puzzle

A fast, juicy, viral merge game built with Vanilla JavaScript, Web Audio API, and custom jelly physics powered by Vite.

## Features
- **Tactile Jelly Physics**: Squishy blobs that settle with dynamic deformation and bounce.
- **Synthesized Audio**: Dynamic sound effects generated in real-time via Web Audio API.
- **Combo System**: Rapid chain merges award exponential score multipliers.
- **Offline & Persistent**: Local storage sync for high scores and audio settings with persistent storage support.
- **Zero Runtime Dependencies**: Pure Vanilla ES2022 modules and native CSS tokens.

## Quick Start
```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
